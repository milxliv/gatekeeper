# Quick Start — Reception Desk

## Daily Startup

1. Open the **GateKeeper** bookmark in your browser
2. If your install asks for a password, log in. Otherwise you're on the
   dashboard — ready to go.

If the page won't load, see **Starting GateKeeper** in the full guide.

## Three Things You'll Do Most

### Check in a walk-in visitor (60 seconds)
**Walk-In** → fill form → **Submit** → take photo → **Approve & Print Badge**

### Check in a pre-registered visitor (30 seconds)
Dashboard → find their name → **Check In** → take photo → print badge

### Enter a pre-visit PDF from a host (2 minutes)
Open PDF → **Pre-Register** in GateKeeper → copy info → **Submit** → print
and file the PDF → delete the email

## Check Them Out When They Leave

Dashboard → **Check Out** next to their name → take back the badge

The visitor's photo is **deleted from disk the moment you click Check
Out** — no manual cleanup needed.

## End of Day

Dashboard → **Check Out All** to clear anyone who forgot to check out
